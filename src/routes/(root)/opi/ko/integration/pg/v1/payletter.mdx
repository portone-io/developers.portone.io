## 채널 설정하기

- [결제대행사 채널 설정하기](/opi/ko/integration/ready/readme#3-결제대행사-채널-설정하기)의 페이레터 채널 설정 내용을 참고하여 채널 설정을 진행합니다.

## 가능한 결제 수단

- **결제창 일반결제**
  - 카드
  - 실시간 계좌이체
  - 가상계좌
  - 휴대폰 소액결제
  - 상품권 : 문화상품권, 도서문화상품권, 스마트문상
  - 간편결제 : 카카오페이, 네이버페이, 토스페이, 페이코, 삼성페이

- **결제창 빌링키 발급 및 결제**
  - 카드

## SDK 결제 요청하기

결제 요청 시에는 [JavaScript SDK](/sdk/ko/v1-sdk/javascript-sdk/readme) `IMP.request_pay(param, callback)` 을 호출해야 합니다.

### 주요 파라미터 설명

<Parameter flatten>
  - channelKey: string

    **채널키**

    결제를 진행할 채널을 지정합니다.

    포트원 콘솔 내 \[결제 연동] - \[연동 정보] - \[채널 관리] 에서 확인 가능합니다.

  - merchant\_uid: string

    **주문번호**

    매번 고유하게 채번되어야 합니다. **영문, 숫자만** 입력 가능하며 최대 50자입니다.

  - name: string

    **주문명**

    최대 100자입니다.

  - amount: number

    **결제금액**

  - pay\_method: string

    **결제수단**

    페이레터는 결제창을 띄울 때 결제 수단을 반드시 하나 지정해야 합니다.

  - buyer\_name: string

    **구매자 이름**

    최대 20자입니다.
</Parameter>

## SDK 빌링키 발급 요청하기

페이레터는 빌링키 발급 전용 API 를 제공하지 않습니다. 결제창에서 결제와 발급이 함께 일어나므로 발급 및 결제 요청으로 진행해야 합니다.

## 유의사항

- `customer_id` 는 최대 50자입니다. 단 **도서문화상품권으로 결제할 때는 최대 30자**입니다.
- **문화상품권은 5,000원 · 10,000원 · 50,000원만 결제할 수 있습니다.**
- **가상계좌 결제는 취소할 수 없습니다.** 부분 취소도 불가합니다.
- 페이레터는 승인 결과를 웹훅으로 전달합니다. 결제창을 닫은 이후에 결제가 성공 처리될 수 있으므로, 웹훅을 연동하여 결제 실패 상태에서 결제 성공 상태로 바뀌는 경우를 처리해야 합니다.
