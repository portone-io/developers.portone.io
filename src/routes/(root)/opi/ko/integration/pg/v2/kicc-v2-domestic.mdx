## 채널 설정하기

- [결제대행사 채널 설정하기](/opi/ko/integration/ready/readme#3-결제대행사-채널-설정하기) 페이지의 내용을 참고하여 채널 설정을 진행합니다.
- 해외 결제(위챗페이 / 알리페이 플러스)를 이용하시려면 [이지페이(KICC) 해외결제](/opi/ko/integration/pg/v2/kicc-v2-global) 문서를 참고해 주세요.

## 가능한 결제수단

- **결제창 일반결제**

  `payMethod` 파라미터를 결제수단에 따라 아래와 같이 설정해야 합니다.

  - 신용카드: `CARD`
  - 실시간 계좌이체: `TRANSFER`
  - 가상계좌: `VIRTUAL_ACCOUNT`
  - 휴대폰 소액결제: `MOBILE`
  - 간편결제: `EASY_PAY`

- **결제창을 통한 빌링키 발급**

  `billingKeyMethod` 파라미터를 발급 수단에 따라 아래와 같이 설정해야 합니다.

  - 카드: `CARD`
  - 네이버페이: `EASY_PAY`

- **API 빌링키 결제**

  결제창으로 발급한 빌링키를 이용하여 `POST /payments/{paymentId}/billing-key` 또는
  `POST /payments/{paymentId}/schedule`로 결제할 수 있습니다.

## SDK 결제 요청하기

결제 요청 시에는 `requestPayment` 함수를 호출해야 합니다.
`channelKey`에 이지페이(KICC) 채널의 채널 키를 입력해 주세요.
이 문서에서 안내하는 바이트 길이는 EUC-KR 인코딩을 기준으로 합니다.

아래는 이지페이(KICC) 카드 결제 요청 예시입니다.

<Tabs>
  <Tabs.Tab title="SDK 결제 요청">
    ```ts
    import * as PortOne from "@portone/browser-sdk/v2";

    function requestPayment() {
      PortOne.requestPayment({
        storeId: "store-4ff4af41-85e3-4559-8eb8-0d08a2c6ceec", // 고객사 storeId로 변경해 주세요.
        channelKey: "channel-key-9987cb87-6458-4888-b94e-68d9a2da896d", // 콘솔 결제 연동 화면에서 채널 연동 시 생성된 채널 키를 입력해 주세요.
        paymentId: `payment-${crypto.randomUUID()}`,
        orderName: "나이키 와플 트레이너 2 SD",
        totalAmount: 1000,
        currency: "KRW",
        payMethod: "CARD",
      });
    }
    ```
  </Tabs.Tab>
</Tabs>

### 문자 입력 유의사항

이지페이(KICC)는 일부 EUC-KR 기반 시스템에서 저장할 수 없는 이모지 사용을 제한합니다.
이모지를 입력하면 결제창에서 문자가 깨져 표시될 수 있으므로 사용하지 않아야 합니다.

- `paymentId`에는 영문 대소문자, 숫자, 하이픈(`-`), 밑줄(`_`)만 사용할 수 있습니다.
- `orderName`과 `products[].name`에는 한글, 영문, 숫자, 공백과 기본 문장 부호(`(`, `)`, `[`, `]`, `-`, `.`)만 사용해야 합니다.
- `customer.fullName`에는 한글, 영문, 공백만 사용할 수 있습니다.
- 작은따옴표(`'`), 큰따옴표(`"`), 꺾쇠괄호(`<`, `>`), 역슬래시(`\`), 세미콜론(`;`), 세로줄(`|`), 줄바꿈 문자는 사용할 수 없습니다.

자세한 내용은 [이지페이(KICC) 특수문자 사용 제한 가이드](https://docs.kicc.co.kr/docs/online-payment/common/special-character/)를 참고하세요.

### 카드 결제 유의사항

#### 상점 부담 무이자 할부

`card.useFreeInterestFromMall` 또는 `easyPay.useFreeInterestFromMall`을 `true`로 설정할 때는
아래 조건을 모두 충족해야 합니다.

- `card.cardCompany`, `card.availableCards`, `easyPay.availableCards` 중 결제수단에 해당하는
  파라미터에 무이자를 적용할 카드사를 한 곳 이상 입력해야 합니다.

- 선택한 모든 카드사에 대응하는 `installment.freeInstallmentPlans` 항목을 입력해야 합니다.

- 각 `freeInstallmentPlans.months` 배열에 할부 개월을 한 개 이상 입력해야 합니다. 빈 배열은 허용되지 않습니다.

조건을 충족하지 않으면 결제창 호출 전에 오류가 반환됩니다.

#### 카드사 포인트

`card.useCardPoint`를 `true`로 설정할 때는 `card.cardCompany` 또는 `card.availableCards`에
카드사를 한 곳 이상 입력해야 합니다. `card.availableCards`를 사용하면 목록에 포함된 모든 카드사에
카드사 포인트 사용 설정이 적용됩니다.

대상 카드사를 입력하지 않으면 결제창 호출 전에 오류가 반환됩니다.

## 결제창 빌링키 발급

빌링키 발급 요청 시에는 `requestIssueBillingKey` 함수를 호출해야 합니다.
이지페이(KICC)는 카드와 네이버페이 빌링키 발급을 지원합니다.

        channelKey: "channel-key-9987cb87-6458-4888-b94e-68d9a2da896d", // 콘솔 결제 연동 화면에서 채널 연동 시 생성된 채널 키를 입력해 주세요.

        `firstName`과 `lastName`이 존재하는 경우 `{firstName} {lastName}`이 구매자 이름으로 전달됩니다.

      - lastName?: string

        **구매자 성**

        `lastName`을 입력하는 경우 `firstName`도 필수로 입력해야 합니다.

      - phoneNumber?: string

        **구매자 연락처**

        숫자만 사용하여 11자 이내로 입력해야 합니다.

      - email?: string

        **구매자 이메일**

        50자 이내의 이메일 형식이어야 합니다.
    </Parameter.Details>

  - easyPay?: object

    **간편결제 정보**

    <Parameter.Details>
      - easyPayProvider: string

        **간편결제수단**

        네이버페이(`NAVERPAY`)만 지원합니다.

      - availablePayMethods: string\[]

        **노출을 허용할 결제수단의 종류**

        네이버페이 빌링키 발급 시 **필수 입력**이며, 첫 번째 값만 사용됩니다.

        - 네이버페이 카드: `CARD`
        - 네이버페이 포인트/머니: `CHARGE`

      - availableCards?: string\[]

        **노출을 허용할 카드사 목록**

        `card.cardCompany`와 동일한 값을 사용합니다.
    </Parameter.Details>

  - locale?: string

    **결제창 언어**

    카드 빌링키 발급 시에만 전달되며 아래 언어를 지원합니다.

    - 한국어: `KO_KR`
    - 영어: `EN_US`
    - 일본어: `JA_JP`
    - 중국어: `ZH_CN` 또는 `ZH_TW`
</Parameter>

## API 빌링키 결제 요청하기

## API 지원 기능

이지페이(KICC)는 포트원 V2 API를 통해 아래 기능을 지원합니다.

- 카드 및 네이버페이 빌링키 결제
- 예약 결제
- 빌링키 삭제
- 결제 취소
- 에스크로 배송 정보 등록, 수정, 조회, 구매 확정
- 현금영수증 발급, 조회, 취소
- 가상계좌 말소

### 에스크로 API 유의사항

- 배송 정보 등록 및 수정 시 물류회사(`logistics.company`)는 필수입니다.
  송장 번호(`logistics.invoiceNumber`)는 30바이트 이내로 입력해야 합니다.

- 이지페이(KICC)는 아래 물류회사만 지원합니다.

  - CJ대한통운: `CJ`
  - 롯데글로벌로지스: `LOTTE`
  - 로젠택배: `LOGEN`
  - 동원로엑스: `DONGWON`
  - 우체국: `POST`
  - 한진택배: `HANJIN`
  - 기타: `ETC`

### 현금영수증 API 유의사항

- 이지페이(KICC)를 통해 포트원 외부 결제 건의 현금영수증 발급 및 취소를 지원합니다.

- 현금영수증 발급 시 아래 파라미터는 필수입니다.

  - `amount.vat`: 부가세 금액
  - `customer.identityNumberType`: 식별 정보 유형 (`CARD`, `PHONE`, `BUSINESS`)

- `customer.identityNumber`는 숫자만 사용하여 50자 이내로 입력해야 합니다.

- `customer.email`은 20자 이내의 이메일 형식이어야 하며, 영문 대소문자와 숫자 외에는 `@`, `.`,
  `_`, `-`만 사용할 수 있습니다.

- `paymentId`는 영문 대소문자, 숫자, 하이픈(`-`), 밑줄(`_`)만 사용하여 40자 이내로 입력해야 합니다.

- `customer.name`은 20바이트까지, `orderName`은 50바이트까지만 전달됩니다.

### 결제 취소 API 유의사항

#### 비동기 취소

가상계좌 입금 후 환불과 휴대폰 소액결제 익월 환불은 이지페이(KICC)가 요청을 접수한 뒤 환불이
이루어지는 **비동기 방식**으로 처리됩니다. 휴대폰 소액결제 당월 환불과 그 외 결제수단은 실시간으로
취소됩니다.

- 응답의 `status`가 `REQUESTED`(취소 요청)로 반환되며, 이 시점에는 취소가 확정되지 않습니다.
  응답만으로 주문 상태를 취소로 변경하지 않도록 유의해 주세요.

- 환불이 완료되면 포트원이 결제 취소 웹훅을 발송하므로 **웹훅 연동은 필수**입니다.

- 환불 계좌(`refundAccount`)를 필수로 입력해야 하며, 환불 금액은 요청일 다음 날(D+1)에 해당 계좌로
  입금됩니다.

#### 에스크로

- 에스크로 결제는 부분 취소할 수 없으며 전액 취소만 지원합니다.
