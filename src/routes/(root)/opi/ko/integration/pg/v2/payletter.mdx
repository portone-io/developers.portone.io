## 채널 설정하기

- [결제대행사 채널 설정하기](/opi/ko/integration/ready/readme#3-결제대행사-채널-설정하기)의 페이레터 채널 설정 내용을 참고하여 채널 설정을 진행합니다.

## 가능한 결제 수단

- **결제창 일반결제**
  - 카드
  - 실시간 계좌이체
  - 가상계좌
  - 휴대폰 소액결제
  - 상품권 : 문화상품권, 도서문화상품권, 스마트문상
  - 간편결제 : 카카오페이, 네이버페이, 토스페이, 페이코, 삼성페이

- **결제창 빌링키 발급 및 결제**
  - 카드

## SDK 결제 요청하기

결제 요청 시에는 [requestPayment](/sdk/ko/v2-sdk/payment-request?v=v2) 함수를 호출해야 합니다.
`channelKey` 파라미터에 결제 채널 연동 후 생성된 채널 키값을 지정하여 페이레터 채널 사용을 명시해주세요.

`payMethod` 파라미터로 결제 수단을 지정합니다. 페이레터는 결제창을 띄울 때 결제 수단을 반드시 하나 지정해야 하므로, 결제 수단을 고르는 화면이 따로 제공되지 않습니다.

## SDK 빌링키 발급 요청하기

페이레터는 빌링키 발급 전용 API 를 제공하지 않습니다. 결제창에서 결제와 발급이 함께 일어나므로 [requestIssueBillingKeyAndPay](/sdk/ko/v2-sdk/billing-key-and-pay-request?v=v2) 함수를 호출해야 합니다.

[requestIssueBillingKey](/sdk/ko/v2-sdk/billing-key-request?v=v2) 는 지원하지 않습니다.

## 상점명

`storeDetails.storeName` 이 페이레터의 `service_name` 으로 전달되어 결제창과 결제 알림에 표기됩니다. **최대 20자**입니다.

**삼성페이·토스페이는 페이레터가 이 값을 필수로 요구하므로 반드시 입력해야 합니다.**

## 가상계좌

- 채번된 계좌 정보는 결제창이 닫힌 뒤 전달되며, 입금이 완료되면 웹훅으로 다시 알려드립니다.
- **가상계좌 결제는 취소할 수 없습니다.** 부분 취소도 불가합니다.
- 현금영수증은 페이레터와 별도 계약이 필요합니다.

## 유의사항

- `paymentId` 에는 **영문과 숫자만** 입력할 수 있으며 최대 50자입니다.
- `orderName` 은 최대 100자입니다.
- `customer.customerId` 는 최대 50자입니다. 단 **도서문화상품권으로 결제할 때는 최대 30자**입니다.
- `customer.fullName` 은 최대 20자입니다.
- **문화상품권은 5,000원 · 10,000원 · 50,000원만 결제할 수 있습니다.**
- 페이레터는 승인 결과를 웹훅으로 전달합니다. 결제창을 닫은 이후에 결제가 성공 처리될 수 있으므로, 웹훅을 연동하여 결제 실패 상태에서 결제 성공 상태로 바뀌는 경우를 처리해야 합니다.
